## What I understood

The Cold Start Algorithm is a way to accelerate onboarding into a new team: understand the main problems the team is facing, build initial connections with key people, and find where you can create real impact early.

## Key points

- First 25 min of each 1:1: listen, only interrupt to clarify something you don't understand
- Next 3 min: ask about the biggest challenge they see
- Last 2 min: ask how they prefer to be communicated with

## Practical application

Any time you join a new team or company.

## Explain

### In one sentence

Treat your first weeks in a new role like a recommender system's cold start: gather signal fast through structured conversations before trying to add value.

### How it works

Borrowed from the "cold start problem" in recommendation systems, where there's no data yet on a new user, so the system needs a fast way to gather signal. Applied to a career, it means running the same structured conversation with as many people as possible in your first weeks, instead of guessing what to fix. The patterns that repeat across those conversations point to where the real problems are and where you can help.

### Example

Joining a new team, book 1:1s with everyone you'll work with in the first month, run each one with the structure above, and look for the problems that keep coming up. That overlap is your first project.

### Trade-offs

Speeds up trust and avoids wasted early effort, since people feel heard before you start changing things. Falls apart if you skip the listening and jump to solutions, or if you only talk to a narrow group and miss the real pattern.

## Next step

Apply it in the next new team or company.
